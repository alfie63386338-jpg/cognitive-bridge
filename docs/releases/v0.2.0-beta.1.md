# Cognitive Bridge v0.2.0-beta.1

**Release date:** 2026-09-04

Cognitive Bridge v0.2.0-beta.1 is an experimental prerelease for turning user-provided AI conversation records and other cognitive Source into a user-owned Obsidian knowledge base.

Use a new, disposable, or backed-up test Vault. Never upload private Source or a generated personal Vault to GitHub.

## Highlights

- Paste prepared Markdown Source directly; manual file splitting or ZIP creation is no longer required.
- Use pasted text, one Markdown file, a structured directory, or a structured Source ZIP through one format-neutral normalization pipeline.
- Fail closed on unsafe ZIP members and resource-limit violations while preserving content-stable Source identity.
- Record path-minimized Source Registry entries and deterministic build fingerprints without claiming runtime or Skill-loader attestation.
- Keep instructions embedded in historical Source from changing current scope, permissions, destination, or methodology.
- Preserve a durable, reusable, non-decorative AI-originated term as an optional `A0 / proposed / unconfirmed` Concept without treating creation, passive agreement, or continued conversation as user Adoption.
- Keep prior generated nodes as knowledge-state context, never automatic evidence of later user uptake.

## Compatibility

- Protocol version remains `1`.
- Schema version is `1.1`.
- The six Note Types and existing Origin, Adoption, Evidence, Evolution, Question, Seed, latent-link, and User Decision taxonomies remain unchanged.
- The published v0.1.0-beta.1 release remains available as the historical baseline.

## Known limitations

- This Beta is not production-ready.
- First Build is better tested than arbitrary Incremental Update and full human-edit merging.
- Cognitive output still requires human review.
- Native v0.2 installation and portable export remain platform-specific and require separate verification.
- No license has been selected. No license file accompanies this release, and the release does not itself grant reuse rights beyond applicable platform terms.

## Getting started

1. Prepare one evidence-rich `cognitive-bridge-source.md` using a prompt under `prompts/`.
2. Paste it into an Agent running Cognitive Bridge, or provide it as a Markdown file.
3. Use a new test Obsidian Vault.
4. Open `Cognitive-Bridge/01_MOC/MOC - Cognitive Bridge.md` after completion.

See the README, CHANGELOG, and the v0.2 engineering, test, and product-patch reports for full evidence and boundaries.
