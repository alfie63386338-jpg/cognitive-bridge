# Cognitive Bridge v0.1 Beta 1

## What Cognitive Bridge does

Cognitive Bridge turns longitudinal AI conversations and other user-provided cognitive sources into a user-owned Obsidian knowledge system while preserving provenance, uncertainty, evolution, and reviewable latent connections.

## Beta purpose

Beta 1 tests whether a user without the development directory can obtain the Skill, prepare Source, invoke the workflow, transfer files, and open a usable Obsidian-native result.

The primary path is:

```text
Gemini Source → Cognitive Bridge → Test Obsidian Vault
```

## Recommended testing path

1. Download the Release ZIP or clone the repository.
2. Use `prompts/prepare-source-gemini.md` when the relevant history is in Gemini.
3. Keep the resulting Source Package private.
4. Use a new disposable or backed-up Obsidian test Vault.
5. Run the Skill from `SKILL.md` and open the generated main MOC.
6. Report installation and transfer friction with synthetic or anonymized evidence.

## Current limitations

- Experimental Beta; not v1.0 or production-ready.
- First Build is preferred.
- Incremental Update is not fully validated.
- Human-edit merge protection is not mature.
- Cognitive content quality still requires later Cognitive QA and human review.
- Native installation support varies by platform and remains unverified unless listed otherwise in `docs/installation-matrix.md`.

## Privacy warning

Never upload a real Source Package, private generated Vault, or private QA log to the public repository, a fork, or a GitHub Issue. Use synthetic or anonymized reproductions and remove credentials, tokens, and personal data.

## Known unvalidated areas

- end-to-end incremental updates;
- automatic preservation/merge of arbitrary human edits;
- native Skill installation on specific third-party Agent platforms;
- portable Vault ZIP export by Agents without local filesystem access;
- cognitive quality across diverse real-world Source Packages.
