# Reference Implementation #1

Cognitive Bridge originated from a successful real-world workflow in which a long-term AI conversation history was reconstructed into an Obsidian-native cognitive genealogy.

The private content of that implementation is **not** part of this package. Only the transferable method was retained.

The reference implementation demonstrated that the following practices were useful in combination:

- excluding ordinary chats and retaining durable cognitive material;
- separating Origin, Adoption, and Evidence;
- preserving AI/user co-construction rather than assigning all polished language to the user;
- keeping Seeds intentionally incomplete;
- reconstructing evolution with traceable dates and explicit gaps;
- discovering latent cross-time and cross-domain connections while marking them as proposed;
- writing atomized Markdown notes with MOCs and WikiLinks;
- using a separate engineering pass to build and validate the actual Vault.

The universal Skill must never copy the original user's themes, MOC count, terminology, chronology, or personal worldview into another user's knowledge base.
